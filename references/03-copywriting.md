# 03 · Copywriting for maximum slop

The interface promises a product. The copy promises a **movement**.

Voice: confident, breathless, vague. Never explain the mechanism. Never name a customer.
Never use a number you could verify.

---

## 1. The six laws of slop copy

1. **Adjectives over nouns.** "AI-powered" is a noun now.
2. **Outcomes over features.** Don't say what it does; say it "unlocks 10x".
3. **Speed is a feature.** Everything happens "in seconds".
4. **Scale is proof.** "10,000+ teams" is an argument.
5. **No specifics.** A specific number invites a question.
6. **One emoji per idea.** ✨ for magic, 🚀 for speed, 💜 for love, 🔒 for trust.

## 3. The lexicon

Use at least eight of these per page. Duplicates don't count, so spread them out.

### Capability

| Word | Use it to… |
|------|-----------|
| AI-powered | prefix any noun |
| cutting-edge | describe technology from 2023 |
| next-generation | describe the same technology |
| state-of-the-art | describe it again |
| intelligent | describe a dropdown |
| autonomous | describe a cron job |
| predictive | describe a sum |
| generative | describe anything with a text box |
| seamless | describe an integration you haven't built |
| native | describe an API call |

### Outcome

| Word | Use it to… |
|------|-----------|
| supercharge | verb for "improve" |
| unlock | verb for "allow" |
| elevate | verb for "improve" (premium) |
| empower | verb for "allow" (HR) |
| revolutionize | verb for "change" |
| transform | verb for "change" (Enterprise) |
| accelerate | verb for "go faster" |
| scale | verb for "grow" |
| streamline | verb for "simplify" |
| optimize | verb for "fix" |
| 10x / 100x | units of productivity |
| in seconds | unit of time |
| effortless | unit of effort |
| frictionless | unit of friction |

### Proof

| Phrase | Meaning |
|--------|---------|
| Trusted by 10,000+ teams | we have users, probably |
| Loved by 50,000+ builders | same users, different noun |
| 4.9/5 from 2,800+ reviews | invented |
| 99.9% uptime | aspirational |
| SOC 2 Type II | slideware |
| Enterprise-grade | has a login page |
| Backed by top-tier investors | a angel wrote a check |
| As featured in TechCrunch | a press release |
| #1 platform for {category} | self-reported |

### Magic

`✨ magic`, `🚀 rocket`, `💜 love`, `⚡ lightning`, `🧠 intelligence`, `🔒 trust`, `🌍 global`,
`🎯 focus`, `🔥 hot`, `🤖 assistant`, `👋 welcome back`, `🧪 beta`.

## 5. Microcopy

Under the primary CTA, always one of:

- 🚀 No credit card required · 14-day free trial · Cancel anytime
- ✨ Join 10,000+ teams already shipping with AI
- 🔒 Enterprise-grade security · SOC 2 Type II
- 💜 Loved by 50,000+ builders worldwide
- ⚡ Set up in seconds — no code required

Under the pricing grid:

> 🔒 Secure payments · 30-day money-back guarantee · Trusted by 10,000+ teams

Under a form:

> We'll never share your email. No spam, ever. Unsubscribe anytime. ✨

> "{Brand} completely {revolutionized/transformed} the way our team {works}.
> We {10x outcome} in the first {week/month} — it honestly feels like {magic}. {emoji}"

## 8. Naming the startup

`{prefix} + {suffix}` — two syllables preferred, three maximum.

Prefixes: `Nex, Lum, Vert, Quant, Orb, Puls, Zen, Aur, Prism, Flux, Nov, Syn, Vant, Aeth, Hel, Kly, Axi, Nim`

Suffixes: `ora, ify, ara, ix, ova, on, ia, ex, us, ly, ance, io`

Examples: Nexora, Lumify, Vertara, Quantix, Orbova, Pulsar, Zenith, Aurion, Prismata,
Fluxly, Novance, Synthio, Vanta, Aether, Helix, Klyra.

Tagline patterns:

- The all-in-one {category} to supercharge your workflow.
- AI-powered {category} for modern teams that ship at 10x speed.
- The future of work is here — and it's an AI-powered {category}.

## 9. FAQ answers

Every answer follows: **enthusiasm → reassurance → vague capability → emoji.**

> **Is {Brand} really free to start?**
> Absolutely! Our Starter plan is free forever — no credit card required. Upgrade anytime
> to unlock unlimited workflows. ✨
>
> **How is my data protected?**
> Your data is encrypted in transit and at rest (AES-256) and we're SOC 2 Type II
> certified. We never train models on your data. 🔒
>
> **Can I cancel anytime?**
> Of course. One click in your dashboard — no calls, no hoops, no awkward emails. 💜

Never answer with a limitation. Never mention a competitor. Never give a number that
could be checked.
