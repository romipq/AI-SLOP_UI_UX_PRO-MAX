# AGENTS.md — Repository Architecture for `romipq/AI-SLOP_UI_UX_PRO-MAX`

This repository contains **AI-SLOP UI/UX PRO-MAX v2.0** — a 5-skill Agent Skills suite, zero-dependency Python 3 Okapi BM25 search & scaffolding engine, multi-format Design Token exporter, 8-dimension static **Slop Score™** auditor, 12-platform Node.js CLI installer, and standalone prompt collection.

## Directory Map
- `skills/ai-slop-ui-ux-pro-max/` — Core Slop Design Intelligence Engine (`SKILL.md`, 11 domain CSVs + 12 stack CSVs in `data/`, 5 reference manuals in `references/`, and Python 3 CLI in `scripts/`).
- `skills/ai-slop-copywriter/` — LLM & YC SaaS buzzword copywriting skill & lexicon.
- `skills/ai-slop-slopifier/` — 10-pass non-destructive human-to-slop refactoring protocol.
- `skills/ai-slop-components/` — Zero-dependency HTML/Tailwind/CSS visual FX & widget blueprints.
- `skills/ai-slop-pitch-deck/` — Mundane-to-unicorn startup positioning & pricing architect.
- `prompts/` — Copy-paste master system prompt & one-shot prompts.
- `rules/` — Drop-in IDE rule templates for Cursor, Windsurf, Copilot, and universal agents.
- `bin/cli.mjs` — Zero-dependency Node.js installer & runner CLI (`init`, `list`, `doctor`, `audit`, `generate`, `scaffold`).
- `examples/nexusflow-ai-showcase.html` — Interactive 100/100 Grade S+ Slop Studio (5 eras, Landing + Dashboard views, X-Ray Tells inspector).
