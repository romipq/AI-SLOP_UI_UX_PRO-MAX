## Non-Negotiable Dashboard Tropes
1. **Left Sidebar Upsell Box**: Even if the user is logged into an enterprise admin panel, render a glowing purple gradient `"🔥 Upgrade to Pro — $29/mo →"` box pinned at the bottom-left of the sidebar.
2. **4 Identical Top KPI Cards**: Every number must be positive emerald green (`+20.1% from last month ↑` or `+420.69% YoY ↑`). Never display a negative red metric.
3. **Zero-Axis Hockey-Stick Chart**: Render a smooth SVG quadratic spline with an indigo-purple-pink stroke and translucent purple area fill curving relentlessly toward the top-right corner. Omit Y-axis grid labels so nobody can question the math.
4. **The Immortal `Olivia Martin (+$1,999.00)` Row**: Pay homage to the untouched `shadcn/ui` dashboard template by including Olivia Martin, Jackson Lee, and Isabella Nguyen in any Recent Activity or Recent Sales feed.
5. **`✨ AI Insights [NEW]` Badge**: Put a glowing purple `NEW` or `BETA` pill next to at least one sidebar item and include a `"✨ Generate Executive AI Summary →"` button in the header.
