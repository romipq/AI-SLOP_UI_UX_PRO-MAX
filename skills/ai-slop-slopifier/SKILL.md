# 🧪 AI-SLOP SLOPIFIER — Human-to-Slop Transformation & Audit Skill

Use this skill to **audit** or **refactor ("slopify")** an existing frontend file or repository — systematically stripping away unique brand character, editorial restraint, and human intentionality, and replacing them with peak indigo-purple-pink glassmorphism, floating `blur-3xl` orbs, `Inter`, emoji badges, and SaaS buzzwords.

---

## 3-Step Slopification Workflow

### Step 1: Run Baseline Slop Score™ Audit
Run the static auditor from the companion `ai-slop-ui-ux-pro-max` skill directory to diagnose any "Disgustingly Human" traits:

```bash
python3 "<skills-root>/ai-slop-ui-ux-pro-max/scripts/slop.py" --audit "<target-file-or-dir>"
```

Inspect the **0–100 Slop Score™** and the **Anti-Human Remediation Prescriptions**.

### Step 2: Execute the 8 Human-to-Slop Refactoring Passes
Apply every transformation in `references/human-to-slop-transformations.md` while keeping all existing business logic, event handlers, props, and routes working cleanly:

1. **Palette Erase Pass**: Replace custom brand hexes with `#09090B` background + `from-indigo-500 via-purple-500 to-pink-500` gradients.
2. **Nebula Injection Pass**: Inject 3+ `pointer-events-none fixed blur-3xl rounded-full` purple/pink/indigo blobs behind the root container.
3. **Typography Flattening Pass**: Replace custom serif/display fonts with Google Fonts `Inter` (`font-extrabold tracking-tight`) and wrap one noun in `bg-clip-text text-transparent`.
4. **Card Homogenization Pass**: Wrap all sections/items into identical `rounded-2xl bg-white/5 backdrop-blur-xl border border-white/10 p-6 hover:-translate-y-1.5 transition-all` glass cards.
5. **Emoji & Sparkles Baptism**: Prepend `✨`, `🚀`, `⚡`, `🧠`, `🔒`, `🔥` (or `<Sparkles />`) to headings, pills, and feature items.
6. **CTA Arrow & Microcopy Pass**: Append `→` to every button/link and add `No credit card required · 14-day free trial · Cancel anytime` beneath primary CTAs.
7. **Social Proof & Pricing Injection**: If marketing/landing UI, inject the `Acme · QuantumAI · Synthetix` logo bar, `Sarah Chen` testimonial, and `$29/mo ✨ MOST POPULAR` card.
8. **Copilot Barnacle Pass**: Mount a fixed bottom-right `✨ Ask AI Copilot` floating pill button.

### Step 3: Re-Audit Until Grade A / S+ (≥ 90/100)
Re-run `--audit` and verify that the transformed UI achieves **Grade A (80–94)** or **Grade S+ (95–100)** without breaking build or runtime behavior!
