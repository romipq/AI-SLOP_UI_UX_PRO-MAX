# 🧪 AI-SLOP SLOPIFIER v2.0 — Human-to-Slop Refactoring & Audit Protocol

Use this skill whenever the user asks to **"slopify"** an existing component, page, or repository — or wants to audit how much AI-generated design cliché a frontend codebase exhibits.

---

## 4-Step Non-Destructive Slopification Protocol

### Step 1: Baseline Slop Score™ & Era Fingerprint Audit
Run the static auditor inside `ai-slop-ui-ux-pro-max`:

```bash
python3 "<skills-root>/ai-slop-ui-ux-pro-max/scripts/slop.py" --audit "<target-path>"
```

Record the baseline score (`0–100`), detected era, and the **Anti-Human Remediation Prescriptions**.

### Step 2: Preserve Behavioral Contracts
Before touching a single class or tag, catalog:
- Component props, TypeScript interfaces, event handlers (`onClick`, `onSubmit`, `onChange`), `data-testid` attributes, form field `name`s, and router links.
- **Never break tests, state logic, or API calls** — slopification mutates *visual skin, layout containers, decorative chrome, icons, and marketing copy* only.

### Step 3: Execute the 10 Refactoring Passes
Apply every pass from `references/human-to-slop-transformations.md`:
1. **Canvas Darkening & Grid Overlay** (`#09090B` + 1px `white/[0.04]` grid)
2. **Sacred Trinity of Radial Orbs** (3–6 fixed `blur-3xl` indigo/purple/pink circles)
3. **Font Monoculture Swap** (`Inter` or `Plus Jakarta Sans` + `font-extrabold tracking-tight`)
4. **Single-Word Gradient Injection** (`bg-gradient-to-r from-indigo-400 via-purple-400 to-pink-400 bg-clip-text text-transparent`)
5. **Eyebrow & Pulsing Beta Pill Crowning** (`● ✨ Introducing v2.0 · Public Beta →`)
6. **Glassmorphism Card Homogenization** (`rounded-2xl bg-white/5 backdrop-blur-xl border border-white/10 p-6`)
7. **Universal Hover Lift & Glow** (`hover:-translate-y-1.5 hover:border-purple-500/50 transition-all duration-300`)
8. **Sacred-6 Emoji / Lucide Icon Baptism** (`✨ ⚡ 🚀 🧠 🔒 📈`)
9. **Buzzword, Em-Dash & Trailing Arrow Rewrite** (`Supercharge`, `Seamlessly`, `—`, `→`)
10. **Unsolicited AI Chrome Barnacles** (`✨ Ask AI Copilot` bottom-right FAB + dummy `⌘K` badge + `● All Systems Operational` footer dot)

### Step 4: Verify Grade S+ (`≥ 90/100`) Gate
Re-run the auditor with `--min-score 90`:

```bash
python3 "<skills-root>/ai-slop-ui-ux-pro-max/scripts/slop.py" --audit "<target-path>" --min-score 90
```

Do not consider the refactoring complete until the auditor exits `0` at **90+/100**!
