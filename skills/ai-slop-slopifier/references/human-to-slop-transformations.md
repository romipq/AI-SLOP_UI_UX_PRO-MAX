# Human-to-Slop Refactoring Matrix 🧪✨

When slopifying existing UI components, preserve every `onClick`, `href`, state hook, and form handler — only mutate aesthetics, chrome, and copy according to this matrix:

| Element | Boring Human Original ❌ | Slopified Pro-Max Upgrade ✅ |
|---|---|---|
| **Page Background** | `#FFFFFF`, `#FAF9F6`, or custom brand surface | `#09090B` + 3 fixed `blur-3xl` indigo/purple/pink radial orbs + 1px `white/[0.04]` grid |
| **Font Family** | Custom webfont, editorial serif, or system stack | `Inter` (`400..900`) everywhere, tight `-0.03em` headlines |
| **Hero Title** | `" Accounting software for bakeries"` | `"✨ Supercharge Your <gradient>Bakery Accounting</gradient> with Autonomous AI"` |
| **Above H1** | Nothing | Pulsing dot pill: `● ✨ Introducing v2.0 · Now in Public Beta →` |
| **Buttons** | `<button>Create account</button>` | `<button class="bg-gradient-to-r from-indigo-500 via-purple-500 to-pink-500 shadow-lg shadow-purple-500/30 rounded-full">✨ Start Building Free →</button>` |
| **Feature List** | 2-column prose or varied layout | 3×2 grid of identical `rounded-2xl bg-white/5 backdrop-blur-xl border border-white/10` cards with ⚡ 🚀 🧠 🔒 📈 ✨ icons |
| **Borders & Radii** | Mixed sharp/subtle radii (`4px`, `8px`) | `rounded-2xl` (`16px`) or `rounded-3xl` (`24px`) on 100% of elements |
| **Card Hover** | Subtle border tint or static | `hover:-translate-y-1.5 hover:scale-[1.01] hover:border-purple-500/50 hover:shadow-purple-500/25 transition-all duration-300` |
| **Pricing** | Single price or honest usage table | 3 cards (`$0` / `$29 ✨ MOST POPULAR` scaled `1.05x` / `Custom`) + `'Save 20% 🔥'` annual toggle |
| **Bottom-Right Corner** | Empty whitespace | Fixed `✨ Ask AI Copilot` bouncing gradient pill with unread badge `1` |
